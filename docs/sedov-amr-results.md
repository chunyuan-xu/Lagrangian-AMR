# SedovCartesian 测试结果

本文档整理当前 5-7 层 Distance AMR 与两组均匀网格基线的对比结果。三组算例均使用 `end_time=1.0`、相同编译版本和 2 个 MPI ranks。动态 AMR 使用 `L5-L7`，激波保护带为 `distance_band_half_width=0.05`；波后离激波阵面超过约 0.05 后允许减疏。

## 表 1：精度与效率对比

| 算例 | 末帧单元数 | 运行时间 (s) | 激波位置误差 | 密度峰值误差 | 最大能量误差 |
|---|---:|---:|---:|---:|---:|
| 全程 L5 | 1,024 | 20.49 | 0.0050（0.504%） | 12.435% | `9.64e-15` |
| 动态 L5-L7 AMR | 6,040 | 62.94 | 0（0%） | 1.785% | `1.38e-14` |
| 全程 L7 | 16,384 | 330.53 | 0（参考） | 0（参考） | `1.03e-13` |

激波位置取末帧径向密度剖面的最大跳变位置，L7 作为数值高分辨率参考。对应的位置约为：L5 `0.9875`，AMR `0.9925`，L7 `0.9925`。这不是与解析 Sedov 解的绝对误差，而是相对于全程 L7 的离散结果误差。

密度峰值参考值为全程 L7 的 `5.7363`；全程 L5、动态 AMR 分别为 `5.0230` 和 `5.8387`。能量误差取运行日志中所有输出时刻的最大绝对值。

## 效率与负载平衡

相对于全程 L7，动态 AMR：

- 末帧单元数减少 `63.1%`；
- 运行时间减少 `81.0%`；
- 速度约提升 `5.25x`。

末帧动态 AMR 的两个 rank 分别持有 `3017` 和 `3023` 个单元。定义：

```text
imbalance = max(rank_cells) / mean(rank_cells)
```

得到：

```text
imbalance = 1.00099
max(rank_cells) / min(rank_cells) = 1.00199
```

最大 rank 负载仅比平均值高约 `0.099%`，说明 repartition 后单元数量基本均衡。该指标反映单元数平衡，不等价于实际计算时间或内存占用，后续可补充各 rank 的阶段耗时。

## 结果解释

动态 AMR 的激波位置与 L7 一致，密度峰值误差约 1.8%，同时单元数和运行时间显著下降；这是当前结果最适合展示的效率优势。需要同时报告密度峰值误差和剖面误差，避免只展示激波位置而掩盖波后减疏造成的精度损失。
