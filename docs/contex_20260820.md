## 3. Sedov 物理推导与坐标约定

### 3.1 正确的二维 Sedov 轨迹

项目 SedovCartesian 初始条件：`rho_0=1`、`gamma=1.4`、爆炸能量 `E_0=0.244816`。用黄金 `reference/SedovAMR.vtu` 在 `t=0.5` 的物理 `NodeX/NodeY` 压力前沿重新标定：

\[
R_s(0.5)\approx0.7065\approx\sqrt{0.5}.
\]

所以本项目标准归一化为：

\[
\boxed{R_s(t)=\sqrt{t}},\qquad
\boxed{D_s(t)=\frac{1}{2\sqrt{t}}}.
\]

不得使用常速度 `shock_velocity * t`，也不得用某时刻的瞬时速度直接乘时间；Sedov 阵面位置是变速度积分结果。

### 3.2 VTU 中的两套坐标

- `Position`：p4est 逻辑参考坐标，由 `p4est_vtk_write_header` 产生，不随流体运动。
- `NodeX` / `NodeY`：真正的拉格朗日物理坐标，由 `src/io/io_callbacks.h` 写出。

Distance-AMR 必须在 `NodeX/NodeY` 对应的物理坐标上验收。曾经使用逻辑 `Position` 统计半径，误判为“从原点到激波的 L7 历史尾迹”；换用物理坐标后证实绝大多数 L7 都位于实际激波环带或必要的 2:1 halo。

ParaView 查看物理网格：

1. 打开 `.pvtu`；
2. 添加 Calculator；
3. 表达式 `NodeX*iHat + NodeY*jHat`；
4. 勾选 Coordinate Results；
5. 按 `level` 着色。

若版本无 Coordinate Results，计算 `(NodeX-coordsX)*iHat + (NodeY-coordsY)*jHat`，再用 Warp By Vector（Scale Factor = 1）。
