# M6 Mesh adapter、IO 与 Diagnostics 拆分计划

## 1. 基线和目标

M6 从 main `746f831`（M5.5 收口）开始。目标：把 Mesh 适配、IO 与 Diagnostics 拆分为独立模块，且不改变任何输出契约。

当前结构（审计结论）：

- **CellKey / SFC ID**：`Global_SFC_ID` 由 `p4est->global_first_quadrant[mpirank] + local_id` 生成（main.cpp:4559），即全局 SFC 序；`state_invariant_checker.h` 注释声明稳定 CellKey 概念。
- **IO**：`src/io/` 已有 `vtk_writer.h`、`output_stamp.h`、`config_parser`；writer 回调在 main.cpp 的 `IOAlgorithm` 命名空间（4547 起）。
- **Diagnostics**：`src/diagnostics/state_invariant_checker.h` 已有纯单元校验器；`check_state_invariants` p4est adapter 在 main.cpp。

必须保持不变：

- 文件命名、字段、精度、时间元数据与旧路径一致；
- `Global_SFC_ID` 语义、守恒监控、checksum、trace 行为；
- G1/G3 reference、字段和容差 `1e-12`。
