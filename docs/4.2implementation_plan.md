# M4.2 AMRTransfer 抽取计划

## 1. 基线和目标

M4.2 从 main `c62a1a6`（M4.1 收口）开始。目标：把 p4est AMR 数据转移逻辑从 `main.cpp` 的 `Lagrangian_replace_quads`（main.cpp:4063-4460）中抽取为 `src/amr/` 纯接口，旧 callback 保留为 adapter，且不改变任何转移语义或守恒量。

当前结构（审计结论）：

- `Lagrangian_replace_quads` 是 p4est 的 transfer callback，包含两条路径：
  - **coarsen 分支**（`num_outgoing > 1`，main.cpp:4077-4245）：4 个 child → 1 个 parent 聚合（corner、geometry、physical、Mass、Volume、CentroidVelo、Gamma、TotalEnergy、InternalEnergy、Pressure、SoundSpeed）。
  - **refine 分支**（`num_outgoing <= 1`，main.cpp:4246-4458）：1 个 parent → 4 个 child 分发（cell 全复制、corner/geometry/physical 缓冲、Mass/Volume 重算）并做质量/能量守恒校验。
- 该 callback 被 `p4est_refine_ext` / `p4est_coarsen_ext` / `p4est_balance_ext` 注册（main.cpp:5214/5229/5234）。
- `generate_children_info_from_parent`（main.cpp:839）为辅助函数，refine 分支调用。

必须保持不变：

- 所有转移数值公式与字段顺序（含 corner/geometry/physical 缓冲索引映射）；
- 守恒量（质量、动量、总能量、体积）不变；
- `p4est_refine/coarsen/balance_ext` 的注册与调用时序；
- ghost rebuild/exchange 时序、owner/remote 语义；
- G1/G3 reference、字段和容差 `1e-12`。
