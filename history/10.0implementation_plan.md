# M10.0 defines.h 现代化改造：p4est_data_t 上帝对象解体计划

> 本文件为 M10 计划，修订基于 M9 收口后实测代码状态。M9 全程 header-only（不新建 `.cpp`，归 M7.3 范围），M10 延续此约束。

## 1. 基线和目标

M10 从 main `9787c0d`（M9 收口）开始。M9 已把全部包装壳函数迁出 main.cpp（main.cpp 346 行）。M10 目标：解构巨型 C 风格结构体 `p4est_data_t`（defines.h:49 起，约 460 行），实现**配置与状态分离、读写分离**，切断其在数十个底层 callback 中的全局状态污染。`SimulationConfig`/`SimulationClock`（`core/simulation_config.h`）已设计且覆盖大部分目标字段，M10 是"激活已冻结设计"。

**核心约束**：
- M10 全程 header-only，不新建 `.cpp` 编译单元；
- 枚举类型（`MyCoordType`/`MySchemeType`/`CoarseningEnum`/等）与业务结构分离到 `defines_types.h`，供各处引用，不硬删；
- 每个子里程碑 G0 + G1 + G3 强制，任一门禁失败停留当前项。

## 4. 细粒度阶段

### 阶段 10.1：驱逐非安全 IO 句柄

- **M10.1.1**：将 `p4est_data_t` 中 `EnergyFile`/`DistanceFile`/`ErrorFile`（ofstream，defines.h:131-133）移出，改为 `IOCallbacks` 内的文件管理（header-only，遵循 M9 架构，不新建 `.cpp`、不用全局单例）。
  - 写入点：`io_callbacks.h:477`（`StatTotalEnergyError` 内 `EnergyFile <<`）、`io_callbacks.h:138`（`quadrant_write_distance_profiles_callback` 内 `DistanceFile <<`）；`ErrorFile` 只 open 无写入（defines.h:196），一并清理。
  - 校验：串行 `.plt` 诊断文件（`EnergyError.plt`/`DistanceProfiles.plt`）哈希一致；G3 下仅 Rank 0 写盘，无文件竞态。
  - 注：`ofstream` 构造/析构在 MPI 下不可迁移，属设计债务（reconstruction.md §4.1），本阶段只做迁移不改变打开路径语义。

### 阶段 10.2：冻结只读物理配置

- **M10.2.1**：激活 `SimulationConfig`，分**小批次**迁移只读配置字段（非"一次删 20 个"）。`coord_type`/`Scheme_type`/`solver_type` 等枚举↔`SimulationConfig` 的 int 字段做类型化映射（复用 `SolverGate::coordinate_type_from_legacy` 等既有转换）。
  - **前置**：清理 `init/initializer.h:51` 对 `coord_type` 的重写（改从 config 读）；确认 `which_case` 与 `config.problem` 对齐。
  - 每批：G0 编译 + 相关短程 → G1 → G3。不同 `which_case`（Sod/Sedov/Noh）与 `coord_type`（plane/cylinder）路由正确性由 G1 三算例覆盖。
  - 枚举（`MyCoordType`/`MySchemeType`/`CoarseningEnum`/`RefiningEnum`/`DistanceProfileType`/`center_type`）迁 `defines_types.h`，不删。

### 阶段 10.3：隔离动态运行时上下文

- **M10.3.1**：将运行状态（`current_time`/`current_step`/`used_dt`/`delta_time`/`dt_iter`/`local_dt`/`equal_dt`/`last_output_index`）迁入 `SimulationClock` 与新建 `ReductionContext`（全局归约 `total_energy_*` 归此处）。
  - **优先保障** `predict_timestep` 的 `local_dt` 归约链：`local_dt = TimestepReduction::accumulate_local_minimum(...)` → `MPI_Allreduce(MIN)`（hydro_controller.h）不被中断；
  - `current_step`/`current_time` 迁移时同步更新 `simulation_clock()` 快照接口；
  - 底层回调读取 `dt` 只能拿 `Clock` const 引用，禁止写。

### 阶段 10.4：P4estBridge 载体与收官
