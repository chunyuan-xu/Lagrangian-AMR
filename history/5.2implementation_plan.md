# M5.2 Riemann 调用链 phase 化计划

## 1. 基线和目标

M5.2 从 main `b9fa0fa`（M5.1 收口）开始。目标：把 `RiemannSolver`（main.cpp:3452）中的阶段链显式 phase 化，建立 reset→assemble→exchange→solve master→exchange→solve hanging→exchange→force 的声明式阶段序列，并抽取为纯接口。

当前结构（审计结论）：

- `RiemannSolver` 以 `fixed_iter_num` 迭代执行：
  1. `FluxRelaxedResetZero`（reset）
  2. `MatrixAssemble` + `session.exchange()`（assemble + exchange）
  3. `ComputeCornerNodeVelocity` + `session.exchange()`（solve master + exchange）
  4. `ComputeHangingNodeVelocityUsingConstrainedConditionByMasterNodes`（solve hanging）
  5. `session.exchange()`（exchange）
  6. 迭代结束后 `ComputeCornerAndEdgeForce`（force）
- 各阶段已是独立函数；阶段序列与 exchange 边界内联在迭代循环中。

必须保持不变：

- 阶段顺序、迭代次数（`fixed_iter_num`）、exchange 边界；
- 各阶段的数值与 ghost 语义；
- G1/G3 reference、字段和容差 `1e-12`。
