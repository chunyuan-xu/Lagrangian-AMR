# M4.4 AMR Controller 建立计划

## 1. 基线和目标

M4.4 从 main `e573d66`（M4.3 收口）开始。目标：把主循环中的 AMR 阶段编排（refine→exchange→coarsen→balance→partition→rebuild ghost）抽取为 `src/amr/amr_controller.h` 纯接口，主循环改为调用 controller。

当前结构（审计结论）：

- 主循环 AMR 编排块（main.cpp:5005-5036）：
  1. `p4est_refine_ext`（refine）
  2. `ghost_session.rebuild`（rebuild ghost）
  3. `set_allowing_coarsening_tag`（coarsen 门禁）
  4. `p4est_coarsen_ext`（coarsen）
  5. `StatTotalEnergyError`
  6. `p4est_balance_ext`（balance）
  7. `ghost_session.destroy`
- 周期 partition（main.cpp:5040-5047）：`p4est_partition` + destroy ghost。
- 后续 `ghost_session.initialize`（5052）与 `refresh_after_balance`（5056）恢复 ghost。

必须保持不变：

- 阶段顺序与次数（refine→rebuild→tag→coarsen→balance→destroy；partition→destroy→initialize）；
- 每个阶段的 p4est 调用参数（`recursive`/`allowed_level`/`callbackorphans`/`allowcoarsening`/`P4EST_CONNECT_CORNER`/`P4EST_CONNECT_FULL`）；
- ghost rebuild/exchange 时序、owner/remote 语义；
- G1/G3 reference、字段和容差 `1e-12`。
