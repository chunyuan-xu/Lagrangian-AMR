# M4.1 AMR 判据模块化计划

## 1. 基线和目标

M4.1 从 main `70c50b5`（M4.0 收口）开始。目标：把 AMR refine/coarsen 判据从 `main.cpp` 内联实现中彻底分离为 `src/amr/` 纯接口，消除死判据，且不改变任何判据语义。

当前状态（审计结论）：

- **已迁移**：`Lagrangian_refine_err_estimate`（main.cpp:935）与 `Lagrangian_coarsen_err_estimate`（main.cpp:941）已委托 `AMRAgorithm::RefineErrorEstimate` / `CoarsenErrorEstimate`（`src/amr/amr_criteria.h`），并被主循环 `p4est_refine_ext` / `p4est_coarsen_ext` 实际注册（main.cpp:5381/5397）。
- **未注册死代码**：`Lagrangian_init_refine_err_estimate`（main.cpp:816）、`Lagrangian_refine_fixed_estimate`（main.cpp:851）、`Lagrangian_coarsen_fixed_estimate`（main.cpp:893）、`Lagrangian_init_coarsen_err_estimate`（main.cpp:946）——在 `src/` 中仅出现于定义处，零调用、零注册，产生 unused-function 警告。
- **既有纯接口**：`src/amr/amr_criteria.h`（refine/coarsen 判据）、`src/amr/coarsen_family_policy.h`（family coarsen policy）、`src/amr/coarsen_family_policy.h`。

必须保持不变：

- refine/coarsen 判据语义、`refine_coarsen_enum` 分支、level 边界；
- `p4est_refine_ext` / `p4est_coarsen_ext` 注册和调用时序；
- ghost rebuild/exchange 时序、owner/remote 语义；
- G1/G3 reference、字段和容差 `1e-12`。
