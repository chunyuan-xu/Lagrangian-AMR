# M5.1 纯角点数学抽取计划

## 1. 基线和目标

M5.1 从 main `75f44ca`（M4.5 收口）开始。目标：把 main.cpp 中的纯角点数学（2×2 矩阵求解）抽取为 `src/physics/` 纯接口，旧函数保留为对照或委托，不改变算法。

当前结构（审计结论）：

- `BoundaryNodeVelocityComputation`（main.cpp:2186）：纯 2×2 边界求解函数。输入 `CPointBounInfo` ×2 + `CDoubleMatrix` + `CDoubleVector`，输出速度向量。**无 p4est 依赖**，是 FreeBoundary/PressureBoundary/VelocityBoundary/WallBoundary/SymmetryBoundary 分支的纯数学。
- `quadrant_corner_to_point_matrix_assemble_callback`（main.cpp:2017）：p4est corner 遍历，累加各 cell 的 `MarCnData` 与 `RHS` 到角点，含 owner/ghost 逻辑——保留在 main.cpp。
- 调用点：`quadrant_corner_velocity_callback`（2768 区域）用 `BoundaryNodeVelocityComputation` 与 `MatrixInverse`+`MatrixDotVector`。

必须保持不变：

- 所有边界分支公式、阈值（`1e-10`/`1e-12`）、矩阵逆/点乘；
- 角点遍历、owner/ghost 逻辑、守恒量；
- G1/G3 reference、字段和容差 `1e-12`。
